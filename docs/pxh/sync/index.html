Database merge engine for sync.

This is the shared core of every sync mode (directory, SSH, stdin/stdout): merge one pxh database file into the live connection with deduplication, optional secret filtering, an optional incremental watermark, and unsealed-row upgrades. Callers own transport and presentation; this module owns the merge semantics and reports what happened via MergeStats.
